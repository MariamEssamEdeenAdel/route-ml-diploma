# Assignment 01 - Introduction to Programming

This folder contains my solutions to **Assignment 01** from the Introduction to Programming module of my Machine Learning diploma at Route.

## Topics Covered

The assignment focuses on practicing fundamental Python programming concepts, including:

- String manipulation
- Lists and list operations
- Dictionaries
- Loops
- Conditional statements
- User input
- Functions
- Type conversion
- String indexing
- List and dictionary processing
- Basic mathematical operations
- Frequency counting
- Working with nested data structures

## Tasks

The assignment consists of 15 programming problems covering:

1. Separating letters and numbers from a string and calculating their sum
2. Password validation
3. Store discount calculation
4. Finding common elements between two lists
5. Calculating student averages and identifying Honor Roll students
6. Interleaving two strings
7. Calculating the digital root of a number
8. Counting the frequency of elements in a list
9. Calculating factorials and checking divisibility
10. Implementing a simple shopping cart
11. Checking whether a sentence is a palindrome
12. Creating a number square pattern
13. Finding peaks in a list
14. Reversing a dictionary while handling duplicate values
15. Finding vowel positions in a string
