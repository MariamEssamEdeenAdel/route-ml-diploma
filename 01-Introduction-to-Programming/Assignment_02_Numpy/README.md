# NumPy Assignment - Introduction to Programming

This folder contains my solutions to the **NumPy Assignment** from the Introduction to Programming module of my Machine Learning diploma at Route.

## Topics Covered

The assignment focuses on practicing NumPy fundamentals and applying array operations to solve numerical problems, including:

- Creating NumPy arrays
- Generating random values
- Array normalization
- Array indexing and slicing
- Boolean masking
- Finding minimum and maximum values
- Finding values closest to a given value
- Row-wise and column-wise operations
- Calculating sums and means
- Conditional array modifications
- Broadcasting
- Working with multidimensional arrays

## Tasks

The assignment consists of 6 problems covering:

1. Normalizing a random 3×3 array so its values are scaled between 0 and 1
2. Finding the value in an array that is closest to a user-provided value
3. Finding the second-largest value in each column of a matrix
4. Identifying rows whose sum is an even number
5. Replacing multiples of 3 or 5 with `-1`
6. Calculating the mean of each row and centering the row values around zero

## NumPy Skills Practiced

Through these problems, I practiced:

- `np.random`
- `np.min()` and `np.max()`
- `np.mean()`
- `np.sum()`
- `np.abs()`
- `np.where()`
- Boolean indexing
- `axis`
- Array broadcasting
- Array reshaping and multidimensional operations
